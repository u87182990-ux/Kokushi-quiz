# 国試ドリル

診療放射線技師国家試験の過去問クイズ（第67〜78回 全2,400問・解説つき）と、対策問題集（オリジナル270問）。
ニックネーム＋4ケタの数字でログインすると、記録がクラウド（Supabase）に保存され、どの端末からでも続きから使えます。

- `index.html` … トップ（ログイン画面）
- `kakomon/` … 過去問クイズ
- `prep/` … 対策問題集
- `ikougaku/`・`kisoi/`・`sugiura/`・`yamauchi/`・`keisoku/` … 追加ドリル（トップの「追加ドリル」→「えらぶ」で、使う人だけ自分のメニューに出す。一覧は index.html の EXTRA）
- `shared/config.js` … Supabase の URL と anon キー
- `shared/account.js` … ニックネームで保存するしくみ
- `supabase.sql` … Supabase の SQL Editor で1回だけ実行するもの
- `tools/mksite.py` … Claude のページ版からサイト版を作り直すスクリプト

## いつも最新版が出るしくみ（ホーム画面に追加して使う人むけ）

- `sw.js` … サービスワーカー。ページ・問題データ・JS は毎回ネットから最新を取り、つながらない時だけ控えを使う（画像は控え優先）。Supabase の通信にはさわらない。
- `shared/update.js` … 全ページで読みこむ。ホーム画面のアプリにもどった時にサイトが変わっていないか確かめ、5分以上はなれていたら自動で読みこみ直し、短い時は「新しい版があります」を出す。
- `manifest.webmanifest`・`icons/` … ホーム画面に追加した時の名前とアイコン（全画面のアプリ表示）。
- 新しいページを足す時は、`<head>` にほかのページと同じ manifest／apple-touch-icon／`shared/update.js` の行を入れる。
- ホーム画面のアイコンは4種類（`icons/a`〜`icons/d`、はじめは c）。トップの「ホーム画面のアイコン」で選ぶと、`shared/update.js` がそのページの apple-touch-icon と manifest（`manifest-<a|b|d>.webmanifest`）を差しかえる。選んだものは端末の localStorage `kq-icon` に保存。

## アプリ風の画面（下のタブ）
- 画面の下に浮く丸いタブバー（`shared/tabbar.js` と `shared/tabbar.css`）で「ホーム／演習（`#drill`）／模試（`#mock`）／その他（`#me`）」を切りかえる。成績（`#stats`）は「その他」、ブックマーク（`#bm`）は「演習」の中から開く。
- 週間模試（`shared/weekly.js`）：週替わりで1分野・20問・30分。分野は `ROT` の順に毎週月曜で回り、問題は週番号を種にした並べかえで選ぶので全員同じ。過去問ページへの組みこみは `tools/add-weekly.py`（`?start=weekly`、記録は `<LS>-wk` とクラウドの `data.wk`）。トップの「模試」タブは `KQWeekly.info()/read()` で表示だけ。
- 判定画面（答え合わせのあと）の並びは `tools/add-judge.py` で入れている：出典・分野 → 進捗 → 問題 → 選択肢（色は今までどおり：正解＝緑＋「正解」、自分のまちがい＝赤＋「あなたの回答」、ほかは無地）→ 選択と判定 → みんなの正答率 → 解説。mksite.py で作り直したら再実行。
- 問題タグ（`shared/tags.js`）：完璧／復習中／要学習の手動の印。過去問ページへは `tools/add-tags.py`（add-weekly・add-judge のあと）。上のタブ「タグ」と `?start=tags`、`?start=tag1|tag2|tag3` でそのタグを出題。記録は `<LS>-tag`、クラウドは kakomon の `data.tag`。苦手リストとは別。
- ホームの学習レポート（index.html の data-blk="study|score|field30|cal"）：ログイン日数・総学習時間・連続日数／総回答・正答率・正解数（成績と同じ計算）／分野別正答率（過去問・直近30日に解いた問題の最後の答え）／月の学習カレンダー。開いた日は `kq-visit-v1`、学習時間は `kq-time-v1`（`shared/stats.js` が問題のページで、画面が見えていて90秒以内に操作があるときだけ数える）。どちらもクラウド保存の `visit`・`time` に入り、日ごとに大きいほうを残す。
- 難易度（AI推定）：みんなの正答率がない問題（第67〜69回など約600問）に5段階の難易度を `kakomon/difficulty.json` に別データとして持つ。`python3 tools/difficulty.py` で、正答率のある問題から「特徴→正答率」の式を学習して推定（rates.json や questions.json を変えたら再実行）。表示は「難易度（AI推定）」と明記し、正答率の数字とは混ぜない。
- タブバーは過去問型のページ（kakomon／prep／chiryo／chiryo-quiz）にも出る。`tools/add-tabbar.py` で入れている（mksite.py などで作り直したら再実行）。問題を解いている間（`body.in-quiz`）は自動でかくれる。色は「見た目」6種類に合わせて、バーの中だけで切りかえる（問題ページ自体の色はそのまま）。
- `shared/stats.js` … 日ごとの解答数（成績・連続日数・学習カレンダー用）とブックマークを記録。`account.js` がクラウド保存の時にいっしょに送る。
- 問題ページの「☆ 保存」ボタン・`?start=bm|weak|random|unsolved`・`?q=問題id`・`?field=分野` は `tools/addbm.py` でつけている。`tools/mksite.py` で作り直した時は、そのあとに `python3 tools/addbm.py` を実行する。
- 新しいドリルを足す時は、`index.html` の `DRILLS`（成績用）と `EXTRA`（メニュー用）に1行ずつ足す。

## お試し版（ログインなし）
- `demo/` … `https://u87182990-ux.github.io/Kokushi-quiz/demo/` を開くと、そのタブの間はログインなしのお試し版になる（`?demo=1` でも同じ、`?demo=0` で元にもどる）。
- しくみは `shared/account.js` の DEMO。ログイン画面・引っ越し・右上の「ログインして保存」をかくし、記録は端末だけに保存して Supabase には一切送らない。ほかの機能（成績・カレンダー・ブックマーク・メモ・案内キャラなど）はそのまま。
- タブ（sessionStorage）だけの切りかえなので、ふつうのサイトやホーム画面のアプリには影響しない。
- お試し版の記録は localStorage のキーに `kq-demo:` をつけて保存するので、同じブラウザでも本番の記録とまざらない。

## 数字のことば（どの画面も同じ）
- **解いた問題**＝ちがう問題の数。**回答（のべ）**＝同じ問題を2回解いたら2回。**正答率**＝正解した回数÷のべ回答。
- **苦手リスト**＝まちがえた問題。間隔反復で、ステージ1＝あした・ステージ2＝3日後・ステージ3＝7日後が復習日。**復習日の日以降に正解したときだけ**ステージが進み（復習日より前の正解では進まない）、ステージ3で正解すると卒業。まちがえたらいつでもステージ1へ。間隔はリスト入り／ステージ1にもどった時点の試験までの残り日数で決める（11日以上 1・3・7日／7〜10日 1・2・3日／4〜6日 1・1・1日／3日以内 1・1日、復習日は試験の前日まで）。**今日の復習**は1日30問まで（復習日が古い順→みんなの正答率が高いのにまちがえた順。30%以下の難問は後ろ、データなしは中間）。しくみは `shared/srs.js`、問題ページへは `tools/add-srs.py`。記録は苦手リスト（`<LS>-weak`）の各問題に st・due・iv・lr を追加、今日の30問は `<LS>-rv`（クラウドは data.weak・data.rv）。**前回まちがえた問題**は別のリスト（1回正解で消える）。
- 問題ページの数字・ラベルは `tools/fix-counts.py` と `tools/fix-weak.py` で直している（mksite.py で作り直したあとに addbm.py → fix-counts.py → fix-weak.py の順で実行）。苦手リストは間隔反復（上の説明）。fix-weak.py のあと、ほかの add-*.py のあとに `tools/add-srs.py` を実行する。
- 成績のテーマ別：対策問題集・治療ドリルは問題の topic、過去問は `kakomon/themes.json`（`tools/themes.py` がキーワードで自動で分けた目安）。
- 試験日と1日の目標は案内キャラの設定（`KQ.avatar` の exam / goal）に入れて、クラウドにもいっしょに保存。
- 過去問の計算問題138問の解説強化（【よくある間違い】＋選択肢ごとの説明）は `tools/calc-exp/*.txt` が元。`python3 tools/apply-calc-exp.py [quiz-app/src/exp]` で questions.json（と元の解説ファイル）に入れる。治療ドリルは kakomon の解説を使うので、そのあと chiryo の build.py を実行し直す。

## 試験まで3か月の機能（2026-11-21）
- **模試モード**（過去問ページの「模試」・トップの「模試モード」・`kakomon/?start=mock`）：本番と同じ200問（第N回そのまま／全回ミックス＝最新回と同じ分野の数）、タイマー（5時間・2時間30分・なし）、中断・再開（`<記録キー>-mock`、クラウドにも保存）。提出すると合格ライン（6割＝120点）との差・午前／午後・分野ごとの点数。答えた問題は成績と苦手リストにも入る。結果の履歴は `<記録キー>-mockh`。
- **今日やること**（トップの一番上）：1日の目標から今日の残りを出し、苦手リストの卒業待ち → 暗記カードの期限分（最大で半分）→ 弱点分野のまだ解いていない問題 → 新しい問題 の順に組む。`kakomon/?start=today&n=問題数&c=カード枚数`、カードは解き終わったあと `kisoi/?start=due&n=` へ。
- **今日のおすすめ**：正答率がいちばん低いテーマ（のべ5回答以上）から10問。`kakomon/?field=分野&theme=テーマ&n=10`（まだ解いていない問題→正答率の低い問題の順）。
- 計算は `shared/plan.js`（KQPlan）。トップは `kakomon/plan.json`（`python3 tools/plan-meta.py` で questions.json と themes.json から作る）を読む。
- **正答率の色**：40%以下＝赤、60%（合格ライン）＝黄、80%以上＝緑（`KQPlan.pcAttr` と `.pc-c` `.pc-bg`）。
- **画像の拡大**：`shared/zoom.js`。問題の画像をタップで全画面、ピンチ・ダブルタップ・＋－で拡大。
- 試験日のはじめの値は 2027-02-18（第79回）。前に 2027-02-20 と入れていた人は自動で直る。
- 問題ページへの組みこみは `tools/add-study.py`（mksite.py → addbm.py → fix-counts.py → fix-weak.py のあとに実行）。

## オフラインで使う（2026-11-22）
- `shared/offline.js` … `shared/update.js` が全ページで読みこむ。つながっている時に、ページ・問題・解説（約5MB）をうらで自動でスマホに保存する。画像（約11MB）は、トップのマイページ「オフラインで使う」→「画像も保存する」を押した人だけ。どちらも中身が変わったファイルだけ取り直す。
- `offline.json` … 保存するファイルの一覧。**問題・画像・ページを足したり変えたりしたら、毎回 `python3 tools/offline-list.py` を実行してから push する**（忘れても、ひらいたページはこれまでどおり保存されるが、まだひらいていないページ・画像はオフラインで出ない）。
- `sw.js` … オフラインの時は保存した控えを出す。電波が弱くて5秒待っても返事がない時も控えを先に出す。保存していないページは「まだ保存されていません」の画面。
- 記録：オフライン中も localStorage に保存（これまでどおり）。問題ページは電波がもどった時（online）やアプリにもどった時にクラウドにつなぎ直して、たまった記録をまとめて送る。この部分は `tools/offline-patch.py` で入れている（mksite.py で作り直したら、ほかのスクリプトのあとに実行）。
- 図解：計算ドリル（ikougaku）と過去問の計算問題の解説に、「次へ」で1手順ずつ進むSVGの図を出す。図は `shared/zukai.js`（外部ファイルなし・オフラインで動く）。過去問ページへの組みこみは `tools/add-zukai.py`（mksite.py で作り直したら、ほかのスクリプトのあとに実行）。
